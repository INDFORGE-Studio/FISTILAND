## :material-key: Стати адміністратором

Додайте свій SteamID64 (17 цифр, його можна знайти на steamid.io) до `AdminUsers.ini`, по одному в рядку. Файл читається під час запуску сервера, тому після змін перезапустіть сервер. Потім вводьте команди в чаті гри, поставивши спереду `#`.

## :material-console: Команди чату

Статус: **Перевірено** означає, що ми запускали команду на нашому сервері. **Згадано** означає, що її описує публічний посібник, а ми її не перевіряли. У прикладах суми, ім'я гравця та коди предметів — лише приклади: змініть їх на потрібні.

| Команда | Статус | Що робить |
|---|---|---|
| `#ListPlayers` | Перевірено | Показує гравців онлайн. |
| `#ListItems` | Перевірено | Виводить усі коди предметів вашої версії (2 572 у 1.3.4.2) у журнал гри. |
| `#spawnitem Apple`<br>`#spawnitem Water_05l` | Перевірено | Видає вам предмет за його кодом. Використовуйте будь-який код зі списку предметів (див. завантаження нижче). |
| `#SetCurrencyBalance Normal 10000 ІмяГравця` | Перевірено | Встановлює гроші гравця. `Normal` — звичайні гроші, `10000` — сума: змініть її на будь-яке число (500, 100000...). |
| `#ChangeCurrencyBalance Gold 5 ІмяГравця` | Перевірено | Змінює золото гравця. `Gold` — валюта, `5` — сума: змініть як хочете. |
| `#NightBrightness 1` | Перевірено | Яскравість ночі від 0 (темно) до 1 (світло). Лише для вас, не для всього сервера. |
| `#SetTime 12` | Перевірено | Встановлює час доби від 0 до 24. |
| `#ListZombies`<br>`#ListAnimals` | Перевірено | Показує типи зомбі та тварин. |
| `#ListSpawnedVehicles`<br>`#ListSpawnedArmedNPCs` | Перевірено | Показує, що живе у світі. Результат з'являється лише в чаті, не в журналі. |
| `#MapTeleport` | У списку, не перевірено | Телепорт через мапу. |
| `#SetImmortality true`<br>`#SetImmortality false` | Згадано | Імунітет до шкоди: увімкнути, потім вимкнути. |
| `#SetFamePoints 500 ІмяГравця` | Згадано | Встановлює очки слави гравця. |
| `#SetGodMode` | Згадано | Миттєве будівництво, а не невразливість. |
| `#heal` | Недоступно | Не існує у 1.3.4.2. |

## :material-monitor: Запустити безкоштовний локальний тестовий сервер

1. У Steam встановіть безкоштовний інструмент **SCUM Server**.
2. Скопіюйте свої `ServerSettings.ini` і `EconomyOverride.json` до папки `SCUM\Saved\Config\WindowsServer` інструмента. Додайте `[TEST]` до назви сервера, щоб його легко знайти.
3. Запустіть `SCUMServer.exe -log -port=7777` з `SCUM\Binaries\Win64`. Завантаження мапи триває близько двох хвилин.
4. У грі відкрийте поле прямого підключення й введіть `127.0.0.1:7779`. Порт 7777 там не працює.
5. Зупиніть сервер за допомогою Ctrl+C у його вікні.

Журнал сервера — `SCUM\Saved\Logs\SCUM.log` у папці інструмента. Журнал вашої гри, де видно результати команд, лежить у `%LOCALAPPDATA%\SCUM\Saved\Logs`.

## :material-file-cog: Файли налаштувань

| Файл | Що містить |
|---|---|
| `ServerSettings.ini` | Усі налаштування сервера (440 ключів, текст ASCII). |
| `EconomyOverride.json` | Налаштування торговців і ціни за предмет. Кожне значення записане як текст у лапках. |
| `AdminUsers.ini` | Адміністратори, по одному SteamID64 в рядку. |

Що робить кожне значення на FISTILAND, дивіться на [сторінках налаштувань](server/overview.md).

| [ServerSettings_SCUM.ini](downloads/ServerSettings_SCUM.ini){ download="ServerSettings_SCUM.ini" } | **SCUM** | Файл, з яким стартує новий сервер Nitrado, без змін. |

| [EconomyOverride_SCUM.json](downloads/EconomyOverride_SCUM.json){ download="EconomyOverride_SCUM.json" } | **SCUM** | Файл торговців зі стартовими значеннями гри. |
