## :material-key: Стати адміністратором

Додайте свій SteamID64 (17 цифр, його можна знайти на steamid.io) до `AdminUsers.ini`, по одному в рядку. Файл читається під час запуску сервера, тому після змін перезапустіть сервер. Потім вводьте команди в чаті гри, поставивши спереду `#`.

## :material-console: Команди чату

Статус: **Перевірено** означає, що ми запускали команду на нашому сервері. **Згадано** означає, що її описує публічний посібник, а ми її не перевіряли.

| Команда | Що робить | Статус |
|---|---|---|
| `#ListPlayers` | Показує гравців онлайн. | Перевірено |
| `#ListItems` | Виводить усі коди предметів вашої версії (2 572 у 1.3.4.2) у журнал гри. | Перевірено |
| `#spawnitem Apple`, `#spawnitem Water_05l` | Видає вам предмет за його кодом. | Перевірено |
| `#SetCurrencyBalance Normal 10000 ІмяГравця` | Встановлює гроші гравця. | Перевірено |
| `#ChangeCurrencyBalance Gold 5 ІмяГравця` | Змінює золото гравця. | Перевірено |
| `#NightBrightness 1` | Яскравість ночі від 0 (темно) до 1 (світло). Лише для вас, не для всього сервера. | Перевірено |
| `#SetTime 12` | Встановлює час доби від 0 до 24. | Перевірено |
| `#ListZombies`, `#ListAnimals` | Показує типи зомбі та тварин. | Перевірено |
| `#ListSpawnedVehicles`, `#ListSpawnedArmedNPCs` | Показує, що живе у світі. Результат з'являється лише в чаті, не в журналі. | Перевірено |
| `#MapTeleport` | Телепорт через мапу. | У списку, не перевірено |
| `#SetImmortality true` / `false` | Імунітет до шкоди: увімкнути, потім вимкнути. | Згадано |
| `#SetFamePoints 500 ІмяГравця` | Встановлює очки слави гравця. | Згадано |
| `#SetGodMode` | Миттєве будівництво, а не невразливість. | Згадано |
| `#heal` | Не існує у 1.3.4.2. | Недоступно |

## :material-monitor: Запустити безкоштовний локальний тестовий сервер

1. У Steam встановіть безкоштовний інструмент **SCUM Server**.
2. Скопіюйте свої `ServerSettings.ini` і `EconomyOverride.json` до папки `SCUM\Saved\Config\WindowsServer` інструмента. Додайте `[TEST]` до назви сервера, щоб його легко знайти.
3. Запустіть `SCUMServer.exe -log -port=7777` з `SCUM\Binaries\Win64`. Завантаження мапи триває близько двох хвилин.
4. У грі відкрийте поле прямого підключення й введіть `127.0.0.1:7779`. Порт 7777 там не працює.
5. Зупиніть сервер за допомогою Ctrl+C у його вікні.

Журнал сервера — `SCUM\Saved\Logs\SCUM.log` у папці інструмента. Журнал вашої гри, де видно результати команд, лежить у `%LOCALAPPDATA%\SCUM\Saved\Logs`.

## :material-file-cog: Файли налаштувань

| Файл | Що містить |
|---|---|
| `ServerSettings.ini` | Усі налаштування сервера (440 ключів, текст ASCII). |
| `EconomyOverride.json` | Налаштування торговців і ціни за предмет. Кожне значення записане як текст у лапках. |
| `AdminUsers.ini` | Адміністратори, по одному SteamID64 в рядку. |

Що робить кожне значення на FISTILAND, дивіться на [сторінках налаштувань](server/overview.md).

| Файл | Який | Що це |
|---|---|---|
| [ServerSettings_FISTILAND.ini](downloads/ServerSettings_FISTILAND.ini){ download } | **FISTILAND** | Налаштування сервера FISTILAND. |
| [ServerSettings_SCUM.ini](downloads/ServerSettings_SCUM.ini){ download } | **SCUM** | Файл, з яким стартує новий сервер Nitrado, без змін. |
| [EconomyOverride_FISTILAND.json](downloads/EconomyOverride_FISTILAND.json){ download } | **FISTILAND** | Налаштування торговців FISTILAND: без вимоги слави, торговці завжди з товаром і грошима, фіксовані ціни. |
| [EconomyOverride_SCUM.json](downloads/EconomyOverride_SCUM.json){ download } | **SCUM** | Файл торговців зі стартовими значеннями гри. |
| [SCUM_item_codes_1.3.4.2.txt](downloads/SCUM_item_codes_1.3.4.2.txt){ download } | **Дані** | Усі 2 572 коди предметів версії гри 1.3.4.2, по одному в рядку (з команди `#ListItems`). |
| [Armory_SCUM_prices_A0.csv](downloads/Armory_SCUM_prices_A0.csv){ download } | **Дані** | Ціни торговця Armory в базовій грі, зчитані в грі на форпості A0 (близько 380 рядків). |
