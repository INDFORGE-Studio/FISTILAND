# Guerre territoriali

FISTILAND è un server di base contro base. Il territorio che tieni è ciò per cui combatti.

## Bandiere e torrette

- Ogni giocatore può piazzare **3 bandiere**.
- Ogni base può avere **2 torrette**.

## Cargo drop

I cargo drop cadono con regolarità, senza eccessi. Sono un motivo per lasciare la base e incontrare altre squadre.

## Tessere di accesso

Fino a **6 tessere Killbox** e **6 tessere Apex** possono essere in gioco contemporaneamente.

## Respawn rapidi

I respawn sono rapidi ed economici: perdere uno scontro costa minuti, non un'intera serata.

!!! note "Nota"
    Tempi e prezzi esatti sono ancora in fase di taratura e non sono indicati qui.
