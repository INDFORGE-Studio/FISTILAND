# Guerra de territorios

FISTILAND es un servidor de base contra base. El terreno que defiendes es por lo que luchas.

## Banderas y torretas

- Cada jugador puede colocar **3 banderas**.
- Cada base puede tener **2 torretas**.

## Cargo drops

Los cargo drops caen con regularidad, sin exceso. Son una razón para salir de tu base y encontrarte con otras escuadras.

## Tarjetas de acceso

Hasta **6 tarjetas Killbox** y **6 tarjetas Apex** pueden estar en juego a la vez.

## Reapariciones rápidas

Las reapariciones son rápidas y baratas: perder un combate cuesta minutos, no una noche entera.

!!! note "Nota"
    Los tiempos y precios exactos aún se están ajustando y no se indican aquí.
