<p>Množitelj skalira iskustvo zarađeno za svaku vještinu. Sve napreduje standardnom brzinom, streličarstvo i vožnja malo brže.</p>

## :material-chart-line: Iskustvo vještina

| Množitelj | Vještine |
|---|---|
| **1.5** | Streličarstvo (`ArcherySkillMultiplier`), Vožnja (`DrivingSkillMultiplier`) |
| **1** | Svjesnost, Kuhanje, Izdržljivost, Uzgoj, Medicina, Hladno oružje, Puške, Trčanje, Preživljavanje, Zrakoplovstvo, Tučnjava, Kamuflaža, Rušenje, Inženjerstvo, Pištolj, Snajper, Prikrivenost, Krađa, Motocikl |

Naziv postavke je naziv vještine praćen s `SkillMultiplier`, na primjer `RiflesSkillMultiplier=1`.

## :material-star-circle: Ostale postavke napretka

| Postavka | Vrijednost | Što radi |
|---|---|---|
| `EnableSelectedSkillsPromotion` | True | Vještine istaknute trenutnom kampanjom donose bonus. |
| `AllowSkillGainInSafeZones` | False | Nema iskustva unutar sigurnih zona kao što su područja trgovaca. |
| `FameGainMultiplier` | 1 | Brzina kojom se zarađuju bodovi slave. |
| `FamePointRewardOnKill` | 0.5 | Ubojica dobiva 50% bodova slave žrtve. |
| `FamePointPenaltyOnKilled` | 0.5 | Igrač kojeg ubije drugi igrač gubi 50% svojih bodova slave. |
| `FamePointPenaltyOnDeath` | 0.1 | Svaka druga smrt košta 10% bodova slave. |
| `PlantHarvestExamineTimeMultiplier` | 1 | Vrijeme berbe biljke. |
| `FirstPlantHarvestAdditionalChance` | 1 | Bonus šansa pri prvoj berbi biljke. |
