# Прогрес

<p>Множник масштабує досвід, що здобувається для кожної навички. Усе розвивається зі стандартною швидкістю, стрільба з лука та водіння трохи швидше.</p>

</div>

<div class="fl-facts">
<div><b>x1.5</b><span>Стрільба з лука, водіння</span></div>
<div><b>x1</b><span>Усі інші навички</span></div>
<div><b>50%</b><span>Слави, що забирається за вбивство</span></div>
</div>


## :material-chart-line: Досвід навичок

| Множник | Навички |
|---|---|
| **1.5** | Стрільба з лука (`ArcherySkillMultiplier`), Водіння (`DrivingSkillMultiplier`) |
| **1** | Уважність, Кулінарія, Витривалість, Землеробство, Медицина, Холодна зброя, Гвинтівки, Біг, Виживання, Авіація, Бійка, Маскування, Підривна справа, Інженерія, Пістолети, Снайперська стрільба, Скритність, Крадіжка, Мотоцикл |

Назва налаштування складається з назви навички та `SkillMultiplier`, наприклад `RiflesSkillMultiplier=1`.

## :material-star-circle: Інші налаштування прогресу

| Налаштування | Значення | Що воно робить |
|---|---|---|
| `EnableSelectedSkillsPromotion` | True | Навички, які виділяє поточна кампанія, дають бонус. |
| `AllowSkillGainInSafeZones` | False | Досвід не нараховується в безпечних зонах, як-от зони торговців. |
| `FameGainMultiplier` | 1 | Швидкість набору очок слави. |
| `FamePointRewardOnKill` | 0.5 | Вбивця отримує 50 % очок слави жертви. |
| `FamePointPenaltyOnKilled` | 0.5 | Гравець, убитий іншим гравцем, втрачає 50 % своїх очок слави. |
| `FamePointPenaltyOnDeath` | 0.1 | Будь-яка інша смерть коштує 10 % очок слави. |
| `PlantHarvestExamineTimeMultiplier` | 1 | Час збору врожаю з рослини. |
| `FirstPlantHarvestAdditionalChance` | 1 | Додатковий шанс під час першого збору з рослини. |
