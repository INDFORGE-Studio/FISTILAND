# Rozwój

<p>Mnożnik skaluje doświadczenie zdobywane w każdej umiejętności. Wszystko rozwija się w standardowym tempie, łucznictwo i prowadzenie pojazdów nieco szybciej.</p>

<div><b>x1</b><span>Wszystkie pozostałe umiejętności</span></div>
<div><b>50%</b><span>Sławy odbierane przy zabójstwie</span></div>
</div>


## :material-chart-line: Doświadczenie umiejętności

| Mnożnik | Umiejętności |
|---|---|
| **1.5** | Łucznictwo (`ArcherySkillMultiplier`), Prowadzenie pojazdów (`DrivingSkillMultiplier`) |
| **1** | Czujność, Gotowanie, Wytrzymałość, Uprawa, Medycyna, Broń biała, Karabiny, Bieganie, Przetrwanie, Lotnictwo, Bijatyka, Kamuflaż, Wyburzanie, Inżynieria, Pistolet, Snajping, Skradanie, Złodziejstwo, Motocykl |

Nazwa ustawienia to nazwa umiejętności z dopiskiem `SkillMultiplier`, na przykład `RiflesSkillMultiplier=1`.

## :material-star-circle: Pozostałe ustawienia rozwoju

| Ustawienie | Wartość | Co robi |
|---|---|---|
| `EnableSelectedSkillsPromotion` | True | Umiejętności wyróżnione przez bieżącą kampanię dają bonus. |
| `AllowSkillGainInSafeZones` | False | Brak doświadczenia w strefach bezpiecznych, takich jak obszary handlarzy. |
| `FameGainMultiplier` | 1 | Tempo zdobywania punktów sławy. |
| `FamePointRewardOnKill` | 0.5 | Zabójca otrzymuje 50% punktów sławy ofiary. |
| `FamePointPenaltyOnKilled` | 0.5 | Gracz zabity przez innego gracza traci 50% swoich punktów sławy. |
| `FamePointPenaltyOnDeath` | 0.1 | Każda inna śmierć kosztuje 10% punktów sławy. |
| `PlantHarvestExamineTimeMultiplier` | 1 | Czas zbioru rośliny. |
| `FirstPlantHarvestAdditionalChance` | 1 | Bonusowa szansa przy pierwszym zbiorze rośliny. |
