# Guerre de territoires

FISTILAND est un serveur de base contre base. Le terrain que vous tenez est ce pour quoi vous vous battez.

## Drapeaux et tourelles

- Chaque joueur peut poser **3 drapeaux**.
- Chaque base peut avoir **2 tourelles**.

## Largages

Les largages tombent régulièrement, sans excès. Ils sont une raison de quitter votre base et de croiser d'autres escouades.

## Cartes d'accès

Jusqu'à **6 cartes Killbox** et **6 cartes Apex** peuvent être en jeu en même temps.

## Respawns rapides

Les respawns sont rapides et peu coûteux : un combat perdu coûte quelques minutes, pas une soirée entière.

!!! note "Remarque"
    Les délais et les prix exacts sont encore en cours de réglage et ne sont pas indiqués ici.
